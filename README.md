라면 전문 특화 맵 애플리케이션 이용 방법
라면 전문 특화 맵은 사용자의 취향에 맞는 라면집을 쉽고 빠르게 찾을 수 있도록 도와주는 서비스입니다.

1. 위치 정보 사용을 허용하세요.
   앱을 처음 실행하면 위치 정보 사용 권한 요청이 표시됩니다. 「허용」을 선택하면 현재 위치를 기준으로 주변 라면집을 검색할 수 있습니다.

2. 원하는 라면집을 검색하세요.
   상단의 검색창에 가게 이름을 입력하면 원하는 라면집을 빠르게 찾을 수 있습니다.

3. 취향에 맞는 스프를 선택하세요.
   돈코츠, 미소, 이에케 등 원하는 스프 계통의 필터 버튼을 선택하면 해당 조건에 맞는 라면집만 지도에 표시됩니다.

4. 영업 중인 가게만 확인하세요.
   「영업 중만 보기」 기능을 사용하면 현재 시간 기준으로 영업 중인 라면집만 확인할 수 있습니다.

5. 지도 위의 마커를 클릭하세요.
   지도에 표시된 마커를 클릭하면 가게 이름, 스프 종류 등 간단한 정보를 확인할 수 있습니다.

6. 상세 정보를 확인하세요.
   가게 목록이나 마커를 선택하면 가게 이름, 스프 종류, 면 굵기, 주소 등의 상세 정보가 화면에 표시됩니다.

7. 원하는 라면집을 방문하세요.
   현재 위치와 가게 위치를 비교하여 가장 가까운 라면집을 쉽게 찾을 수 있으며, 자신의 취향에 맞는 라면집을 빠르게 선택할 수 있습니다.
